# wiki

Static site built from every repo in a [pull](https://github.com/jbisfun/pull) workspace, published to <https://jbisfun.github.io>: each repo's README is its entry page, next to its `docs/` folder and code reference generated by rustdoc, LDoc and JSDoc.

This repo holds the site's data: per-repo settings in [wiki.toml](wiki.toml), the Jinja templates, the site's own pages, the client assets (Bootstrap theme, JS) and the translation cache. The generator lives in [cpull](https://github.com/jbisfun/cpull) (`src/wiki`, Zig): `cpull wiki build` regenerates what changed (by git object id) into `<workspace>/.pull/cpull/wiki/dist`, `cpull wiki publish` stages it into `../jbisfun.github.io`, and the workspace server (`pull cpull open`) serves it live at `/wiki/`. The site is also published in Traditional Chinese under `/zh-tw/`: Fluent strings for the chrome, machine-translated pages cached in `translations/`.

```sh
just build     # pnpm install, then cpull wiki build
just publish   # stage into ../jbisfun.github.io
```

Docs: [docs/README.md](docs/README.md), [templating](docs/templating.jinja).
