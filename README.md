# wiki

Static site built from every repo in a [pull](https://github.com/jbisfun/pull) workspace, published to <https://jbisfun.github.io>: each repo's README is its entry page, next to its `docs/` folder and code reference generated by rustdoc, LDoc and JSDoc.

This repo is the generator (`wiki`, Zig, in `src/`) and the site's data: per-repo settings in [wiki.toml](wiki.toml), the Jinja templates, the site's own pages, the client assets (Bootstrap theme, JS) and the translation cache. `wiki build` regenerates what changed (by git object id) into `<workspace>/.pull/wiki/dist`, `wiki publish` stages it into `../jbisfun.github.io`, `wiki serve` serves it live with the workspace's forge, CI and reports on its pages, and `wiki mcp` is its MCP server. The site is also published in Traditional Chinese under `/zh-tw/`: Fluent strings for the chrome, machine-translated pages cached in `translations/`.

```sh
just build     # pnpm install, zig build, then wiki build
just publish   # stage into ../jbisfun.github.io
```

Docs: [docs/README.md](docs/README.md), [templating](docs/templating.jinja).
