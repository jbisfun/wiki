# wiki

Static site built from every repo in a [pull](https://github.com/jbisfun/pull) workspace, published to <https://jbisfun.github.io>: each repo's README is its entry page, next to its `docs/` folder and code reference generated by rustdoc, LDoc and JSDoc.

A Rust binary: comrak for markdown, minijinja (Jinja2) templates, and an embedded rolldown that bundles the client JS (Bootstrap, clipboard.js). Git object ids decide what gets regenerated. Per-repo settings live in [wiki.toml](wiki.toml). The site is also published in Traditional Chinese under `/zh-tw/`: Fluent strings for the chrome, machine-translated pages cached in `translations/`.

```sh
just build     # dist/
just publish   # stage into ../jbisfun.github.io
```

Docs: [docs/README.md](docs/README.md), [templating](docs/templating.jinja).
