# gallery-ios

[Fossify Gallery](https://github.com/FossifyOrg/Gallery) 以 SwiftUI 在 iOS 上重新打造，建構於系統照片資料庫（PhotoKit）之上：資料夾即相簿，檔案即照片與影片。

    idl build -c release     # -> build/release/FossifyGallery.ipa (ad-hoc signed; re-sign to install)
    idl install "<device>" FossifyGallery

已移植：資料夾畫面（格狀／清單、方形或圓角縮圖、媒體數量樣式、釘選、自訂拖曳排序、封面圖片、排序、媒體類型篩選、可雙指縮放的欄數、水平捲動、搜尋、顯示所有資料夾內容、預設資料夾、暫時顯示隱藏／排除的項目）；資料夾操作（重新命名、隱藏、排除、鎖定、複製／移動內容、刪除、內容）；媒體畫面，含排序、分組、檢視類型與檔名切換；多選操作（分享、旋轉、加入我的最愛、隱藏、複製／移動、調整大小、修正拍攝日期、編輯、刪除、內容）；全螢幕檢視器，含深度縮放、1:1 縮放、旋轉手勢、即時切換、下滑手勢、亮度手勢、擴充詳細資料、底部操作、投影片播放、列印、在地圖上顯示、變更方向；影片播放器，含拖曳進度列、±10 秒、播放速度、靜音、循環播放、自動播放、記住位置、音量／亮度手勢與獨立畫面播放器；編輯器，含裁切（自由、1:1、4:3、16:9、其他比例）、旋轉、翻轉、濾鏡與繪圖，可儲存為副本或覆寫原始檔案；檔案搜尋；開啟相機；資料夾主畫面小工具（資料夾縮圖，可選擇是否顯示名稱、背景顏色與透明度、文字顏色）；排除的資料夾；App、隱藏項目、排除的資料夾、刪除與資料夾的密碼保護；日期格式與所有適用的設定。

iOS 造成的差異：刪除的媒體會移至系統的「最近刪除」（經過 iOS 自己的確認後），因此沒有 App 內資源回收桶；「隱藏」使用照片的「已隱藏」相簿而非 .nomedia 檔案，因此沒有受管理的隱藏或包含資料夾，也沒有子資料夾分組；檔案無法重新命名或設為桌布；主畫面小工具僅能在 launcher-ios 內使用（iOS 主畫面小工具需要 WidgetKit 擴充功能）；沒有啟動器捷徑、供其他 App 使用的選取／檢視 intent、預設播放器選擇、瀏海設定、App 內語言切換，也沒有設定／我的最愛匯出；濾鏡為 Core Image 照片效果，而音量手勢會變更播放器音量。
